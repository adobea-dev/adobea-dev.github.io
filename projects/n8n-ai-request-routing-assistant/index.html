n8n AI Request Routing Assistant

AI-powered workflow automation system for request intake, classification, routing, logging, and email confirmation.

I built an AI-powered request routing workflow in n8n that captures user requests through a form, classifies each request by category and priority using an AI model, recommends the responsible owner or team, logs structured records in Google Sheets, and sends automated Gmail confirmations to requesters.

This project demonstrates practical AI automation, workflow design, structured data capture, JavaScript-based output parsing, and integration of business tools such as Google Sheets and Gmail.

Tools: n8n, OpenAI, Google Sheets, Gmail, JavaScript
Project Type: AI Automation / Workflow Automation / Internal Tool

Key Features

  • Built a request intake form using n8n
  • Used AI to classify requests by category and priority
  • Recommended the responsible owner or team
  • Generated a clear next action for each request
  • Parsed AI output with JavaScript for structured workflow data
  • Logged request records in Google Sheets
  • Sent automated Gmail confirmation emails
  • Documented the workflow for reproducibility

Business Value

The workflow reduces manual request triage, improves routing consistency, creates a simple source of truth for submitted requests, and helps teams respond faster with clearer ownership and better visibility.
